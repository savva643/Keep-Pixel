# Локальная проверка Keep Pixel 1.1

Проверено на Flutter 3.38.5 / Dart 3.10.4, Node.js с PostgreSQL-движком PGlite (upstream auth/Kompot в тестах подменяются контролируемыми ответами).

- `flutter analyze`: без замечаний после исправлений.
- `flutter test`: 14 проверок — ключ входа против независимого hash-wasm/Node HKDF-вектора с Unicode-паролем, настоящий prelogin/login/2FA-контракт, refresh/revocation, разбор карточек, ошибки API, интерфейс 390×844 и 1440×1000, редактирование/сброс наследования, безопасная распаковка и отклонение обхода путей.
- `npm ci && npm test` в backend: 12 проверок, включая реальные SQL-запросы миграций, профиля, каталога, библиотеки и лицензий, параллельные правки, запрет изменения identity, отозванные сеансы, CORS и выдачу манифеста только владельцу.
- `flutter build web --release --no-web-resources-cdn`: release JS-сборка. Wasm не заявлен: используемый web-плагин защищённого хранилища пока несовместим с Wasm.

После установки на сервер требуется проверка реальным аккаунтом и опубликованным Windows-релизом: см. UPDATE.md. Создание Windows EXE и его запуск требуют Windows; Linux-проверка ZIP/путей не заменяет такой запуск. Оплата и нативная установка игр на мобильных платформах не входят в эту версию.
