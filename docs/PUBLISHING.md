# Публикация игр в Keep Pixel

Разработчик выпускает игру из самого клиента Keep Pixel: **Профиль → Для разработчиков**
(или пункт «Для разработчиков» в меню трея). Отдельного сайта для разработчиков нет.
Модераторы работают в веб-админке `https://keeppixel.necsoura.ru/admin/`.

## Путь игры

1. **Профиль разработчика.** Имя или студия, почта для модерации, сайт. При первом заполнении нужно
   принять правила публикации.
2. **Черновик игры.** Витрина: название, краткое и полное описание, жанр, метки, особенности, языки,
   возрастной рейтинг, движок, трейлер, системные требования, достижения, ссылки.
   Медиа: обложка 3:4, баннер 1920×620, 2–12 скриншотов 16:9 (PNG, JPEG, WebP, GIF до 12 МБ).
3. **Сборка.** ZIP с папкой игры для Windows и путь к exe внутри архива (клиент сам находит exe в ZIP).
   Загрузка идёт частями по 8 МБ; после обрыва или перезапуска клиента продолжается с того же места.
   Сервер сверяет SHA-256 всего архива. Предел задаёт сервер (`KEEP_PIXEL_MAX_BUILD_MB`, по умолчанию 8 ГБ).
4. **Автопроверка** сразу после загрузки:
   - архив: пути без `..` и абсолютных путей, без ссылок и зашифрованных файлов, без повторов,
     до 200 000 файлов и 64 ГБ после распаковки, защита от zip-бомб;
   - файл запуска: настоящий PE (MZ/PE), архитектура x64/x86/arm64, оконная или консольная;
   - движок по содержимому (Unreal, Unity, Godot);
   - Keep Pixel SDK: файлы адаптеров и строки `KEEPPIXEL_SDK_URL` (ASCII и UTF-16) в exe/dll/pck;
   - антивирус ClamAV по всему архиву (контейнер `keeppixel-clamav`).
   Не прошла — статус «Не прошла проверку» с причинами. Прошла — «Ждёт модератора».
5. **Отправка на модерацию.** Кнопка доступна, когда заполнено всё обязательное и есть сборка.
6. **Модератор** скачивает сборку по временной ссылке, запускает её, одобряет или отклоняет с причиной.
   Отдельно проверяет витрину: одобрить, запросить правки (разработчик видит текст в клиенте) или отклонить игру.
7. **Публикация** после одобрения сборки и витрины, как выбрал разработчик: сразу, в выбранную дату
   (фоновая задача раз в минуту) или вручную кнопкой «Опубликовать».

## После выхода

- **Обновление:** новая сборка → автопроверка → модератор. После одобрения она сразу становится текущей,
  прошлая помечается «Прошлая версия», в списке обновлений игры появляется запись. Клиент видит новую
  версию и обновляет игру.
- **Правка витрины** опубликованной игры уходит на проверку; игроки видят прежнюю витрину до одобрения.
- **Скрыть / вернуть:** игра пропадает из магазина, у получивших её игроков остаётся.
- Удалить можно только черновик, который ни разу не публиковался.
- Пока выпускаются только бесплатные игры: платежей в магазине нет.

## Установка у игроков

`GET /games/:id/download` выдаёт манифест со ссылкой, подписанной на 6 часов
(`/static/builds/<id>.zip?exp=&sig=`). Клиент докачивает обрыв через HTTP Range, проверяет размер и
SHA-256, распаковывает архив потоково (файл за файлом, без загрузки в память) и заменяет папку игры
атомарно, сохраняя прошлую версию до успешной распаковки.

## SDK

Наборы для движков раздаёт сервер: `/static/sdk/KeepPixel-UE5-0.2.0.zip`, `-Unity-`, `-Godot-`,
`-Python-` и всё сразу `KeepPixelSDK-0.2.0.zip`. Собираются `python sdk/package.py --output-dir
<Necsoura>/source/services/keeppixel/backend/public/sdk`. Протокол и ограничения — [sdk/README.md](../sdk/README.md).
SDK необязателен: друзья, статус «в игре» и оверлей Shift+Tab работают в лаунчере и без него
(оверлей виден в оконном режиме и в окне без рамки).

## API

Разработчик (токен Necsoura): `GET/PUT /dev/me`, `GET/POST /dev/games`, `GET/PATCH/DELETE /dev/games/:id`,
`POST /dev/games/:id/media?kind=cover|banner|screenshot`, `POST /dev/games/:id/builds`,
`PUT /dev/builds/:id/chunks/:n`, `POST /dev/builds/:id/complete`, `GET/DELETE /dev/builds/:id`,
`POST /dev/games/:id/submit|publish|hide`, `PUT /dev/games/:id/publishing`.

Модератор: `/admin/api/overview`, `/admin/api/games[?filter=&q=]`, `/admin/api/games/:id`,
`POST /admin/api/games/:id/store {decision: approve|changes|reject, note}`,
`POST /admin/api/builds/:id/review {decision: approve|reject, note}`, `.../rescan`, `.../link`,
`POST /admin/api/games/:id/publish|hide|show`, `/admin/api/developers` (+ `block|unblock`),
`/admin/api/log`, `/admin/api/admins`. Модераторы — `KEEP_PIXEL_ADMINS` (UUID через запятую) и таблица `admins`.
